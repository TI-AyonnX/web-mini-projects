Rock Paper Scissors: Ultimate Showdown ✂️🪨📄

Game Description

Rock Paper Scissors: Ultimate Showdown is an interactive, arcade-style browser game built entirely from scratch using modern web fundamentals. It upgrades the classic decision-making game into a fast-paced experience featuring real-time score tracking, dynamic DOM modal popups, automated simulation modes, and full keyboard-driven controls.

Features

* Dual Control Schemes: Play seamlessly using mouse clicks or ultra-responsive keyboard hotkeys.

* Auto-Play Engine: Watch the computer simulate matches continuously at rapid intervals.

* Safe Score Reset: Interactive modal verification prevents accidental score wipes.

* State Persistence: Automatically saves your win/loss/tie record across sessions using localStorage.

* Zero Frameworks: Lightweight, fast performance built strictly with native HTML, CSS, and Vanilla JavaScript.

How to Play

Game Rules

* Rock beats Scissors, loses to Paper.
* Paper beats Rock, loses to Scissors.
* Scissors beats Paper, loses to Rock.

Controls

Action                      Keyboard Shortcut                         Mouse Control

Pick Rock                        R or r                              Click Rock Button
Pick Paper                       P or p                              Click Paper Button
Pick Scissors                    S or s                              Click Scissors Button
Toggle Auto-Play                 A or a                              Click Auto Play Button
Prompt Reset Score               Backspace                           Click Reset Score Button
Confirm Reset                    Y or y                              Click Yes
Cancel Reset                     N or n                              Click No
